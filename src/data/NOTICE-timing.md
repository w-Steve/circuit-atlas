# Timing reference facts

Source: Fédération Internationale de l'Automobile (FIA), event circuit maps.
Each packet in src/circuits/timing contains its exact source URL, PDF SHA-256,
page, document season and extraction date (2026-10-24).

Only factual corner/sector values and approximate diagram registration points
are included. FIA map artwork, logos, fonts and PDF documents are not bundled
or redistributed. This independent project is not affiliated with the FIA.

18 packets use 2026 documents. Mexico, Interlagos, Las Vegas, Lusail and Yas
Marina use explicitly disclosed 2025 reference documents; this does not verify
their 2026 timing arrangement. Start/control positions are approximate, not
surveyed. Local geometry is never rescaled to conceal document discrepancies.
